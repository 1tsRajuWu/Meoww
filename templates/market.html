{# The market. A trading surface, arranged the way trading surfaces have been arranged for thirty years: instruments down the left, the chart in the middle with the order ticket beside it, and the account panels underneath. The arrangement is a convention rather than a copy — nothing here is taken from any particular site, and the only thing borrowed from a trading terminal is the shape, which is the part a reader's eye already knows how to read. What it is honest about, and each of these is deliberate: * **It is a calculator, not a broker.** This page is public and unauthenticated, so there is no order endpoint and no session: the ticket works out what a given spend would get at the observed price and then sends the reader to the command that actually trades. A "Buy" button that looked real and did nothing would be the one dishonest control on the surface. * **Positions and history are named rather than faked.** A position belongs to a member, so the panel says where the reading lives and what to type instead of drawing an empty table that reads as "you hold nothing". * **Everything is read, never written.** The instruments are the registry, the prices are the endpoint, the prints are the candles that were fetched anyway, and the fee label comes from the payload the bot itself uses. There is no number on this page that the bot would disagree with. The chart library is the only third-party request the whole project allows, pinned to an exact version, and it is allowed to fail: the prices, the prints and the ticket do not need it, and the chart card says so in words when it cannot be built. #} {# The theme control is the site's own, imported rather than copied: this page used to include `theme_picker.html`, which the redesign archived — an address that renders a template nobody ships is a 500, which is what this page was answering. #} {% from "_theme.html" import theme_button, theme_menu %} 🐾 {{ symbol }} · {{ name }} — the market {# The shared system first, then this page's own layout — the same order and the same split the console uses: the palette is shared, the arrangement is the page's. #} {# Not deferred, and the only blocking script on the page: it reads the visitor's stored theme and sets `data-theme` before the first paint. #}

This ticket is a calculator: the order itself is placed in Discord with /market buy {{ symbol }} <coins>, where the bot knows who you are. What the ticket shows is what that fill would do — same observed price, same fee.

The treat is banked into Meow Bank, the server's own house account — which is itself one of the systems an administrator can switch off. When a price is older than the freshness window the trade is refused, because the alternative is filling at a number the bot cannot vouch for.

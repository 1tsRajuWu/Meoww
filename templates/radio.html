{{ mark(sections, 'wrong') }}

A live stream has no end

  • “The music is short.” A live source that reports itself finished was cut. The bot asks the engine what ended, retries inside a budget, and says so rather than leaving a silent gap.
  • “Music is broken here.” Every reason is checked before joining: the ffmpeg binary, an Opus library if the host has one, and the voice library. Each missing piece is named separately, because each one is a different fix.
  • The one thing it will not claim Whether a station is reachable is only known from this host. One that answers here can still refuse your network, and the card says so.

03 — When it goes wrong

A live stream has no end

  • “The music is short.” A live source that reports itself finished was cut. The bot asks the engine what ended, retries inside a bounded budget, and says so out loud if it cannot hold the socket — rather than leaving a silent gap that looks like a broken command.
  • “Music is broken here.” Every reason is checked before joining a channel: the ffmpeg binary, an Opus library if the host has one, and the voice library discord.py refuses to open a connection without. Each missing piece is reported separately, because each one is a different fix.
  • The one thing it will not claim It cannot tell whether a station is reachable from your network — only whether it is reachable from this host. A station that answers this deployment can still refuse yours, and the card says so instead of pretending otherwise.

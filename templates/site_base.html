{# The layout every page of this site is one of. There are three pages now instead of one: `/` is the front door, `/systems` is what is in the bot, `/start` is how to add it. They were a single 800-line document whose every question was answered whether or not the reader asked it — *what is this*, *what does it do*, *how do I get it* and *how do I sign in* all in one scroll, which is a page that reads as noise to somebody who arrived with one of those four questions. What is shared lives here rather than in each page, because the failure this layout exists to prevent is the one this project keeps finding: **two places that answer the same question drift**. The head, the navigation, the phone menu, the footer and the asset tokens are written down once, so adding a nav link cannot add it to two pages and not the third. Blocks, and why each is one: * ``title`` / ``description`` / ``theme_color`` — per page, and the theme colour is per page *on purpose*: it is the colour the browser paints its own chrome, which is a property of the page's background rather than of its accent. * ``loader`` — empty by default. The curtain is a first-impression device; a 400 ms fade over every internal navigation is a toll, not a flourish. * ``main`` — the page itself. * ``scripts`` — page-specific behaviour, after ``motion.js`` so a page's script can rely on the reveal classes having been applied. Two names are always in the context and are read here rather than passed down: ``current`` (which nav item is *this* page, so the rail can say so without a script guessing — the server knows) and ``selling`` (whether anything is for sale, which decides whether a Pricing link exists at all; a link to a shop that is switched off is the defect a whole test file exists to prevent). #} {% block title %}{{ bot_name }}{% endblock %} {# Deliberately *not* deferred, and the only blocking script on any page of this site. It reads the visitor's stored theme and sets `data-theme` on ``; a deferred script would run after the first paint, so a visitor who chose Sakura would watch the page arrive indigo and turn rose. It touches nothing the page's content depends on, so a browser that blocks it still renders every page — in the default theme. #} {% block skip_label %}Skip to what's in it{% endblock %} {% block loader %}{% endblock %} {# The menu.

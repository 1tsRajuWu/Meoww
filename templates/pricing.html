{# ------------------------------------------------------------------ #} {# How a licence works #} {# ------------------------------------------------------------------ #}

Licences

One key, activated per server

A licence is bought once and activated on the servers it covers, in Discord — where the bot can already tell who is an Administrator.

◆ Activate where it runs

Run /bot plan in the server and paste the key from your receipt. Each server keeps its own activation, so a reinstall or a rename never needs a support ticket.

⇄ Move it when you move

/bot plan remove:true hands this server's activation back, freeing it for another — useful when an old server is retired and a new one starts.

◈ See what is on

The same command with no options shows this server's plan, its licence state and the limits it carries — the same model this page is drawn from, not a second copy of it.

Try it free first

The free plan is a real product: moderation, leveling, fun and social work on every server, and a licence is only ever needed for the four systems that cost money to run.

{# The old answer promised "a 7-day free trial of Pro features" on every new server. There is no trial in the store (the products are plain monthly subscriptions) and nothing in the bot implements one, so it was a promise two systems would each have to break to keep. #}

Can I try Pro features for free?

There is no trial and no time limit on the free plan — it is permanent, and it includes moderation, automod, leveling, the mini-games, fun and social. Pro adds the support tickets, economy, market, starboard and activity tracker systems; see what each one does before you pay for it.

What payment methods do you accept?

Whatever Lemon Squeezy offers in your country — cards and the local methods they support. The card details are entered on their checkout and are never sent to {{ bot_name }}, which only ever sees that a licence is active.

Can I cancel anytime?

Yes, at any time from the link on your Lemon Squeezy receipt. The plan stays active on your servers until the end of the period you already paid for, and the licence key in /bot plan stops working after that.

Is everything really free?

Yes. Every system {{ bot_name }} has is available in your server today, with no trial and no time limit on any of it. There is no checkout on this page, no card to enter, and no key to activate — an administrator adds the bot and the whole panel is open. See what each system does.

Will it start costing money later?

It might, and we would rather say so than surprise you. A paid tier would be for a network that wants more servers, its own branding, or priority support — not for the systems you already use. If one is ever introduced, this page will say so before anything changes, and no limit is switched on today, so no tier is currently missing anything.

What does adding the bot cost me in permissions?

Discord's own permission to add a bot — that is the whole list. The invite asks for Administrator so that no feature fails later while you work out which permission it wanted; if you would rather not grant that, the second link asks only for the permissions {{ bot_name }} actually uses, and you can grant one more if a system asks for it.

Is my data safe?

The cloud backup is a raw database file in a private bucket that needs a service-role key for every read and write, so access control — not encryption — is what protects it. Only what the systems you switch on need is stored, and the privacy policy lists each kind with how long it is kept.

{% if selling %}

What happens if I downgrade?

Nothing is deleted on a downgrade: the plan changes, and the retention windows in the privacy policy go on applying to what was already recorded. If the paid systems are held back on the free plan, they stop being available until a licence is active again — and activating one puts them back exactly as they were.

{% else %}

What happens if I remove the bot?

Your records are not deleted the moment it leaves: the retention windows in the privacy policy go on applying, so activity counts age out after their own window and queued message history after 90 days. Adding it back picks up from what is still stored.

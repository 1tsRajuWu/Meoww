Get started

Three steps, about five minutes

Add the bot

The invite asks for the two scopes a working bot needs — the bot itself and its commands. Without the second one you get a bot with nothing in the picker.

Run /help

That panel lists every command you can reach, and its ⚡ Open Dashboard button mints a single-use sign-in link for an administrator of that server — valid for fifteen minutes, and only for that server.

Switch off what you don't want

Every system has its own toggle. Turning one off removes its commands from that server's picker and its jobs stop running there; nothing else changes anywhere.

How signing in works

Three ways in

Sign in with Discord

Asks for identify and guilds and nothing else, then shows you the servers you run that the bot is already in. Your access token is used for two lookups in the same request and never stored.

One-time link

Minted by the ⚡ Open Dashboard button on /help, scoped to the one server it was created in, single-use and good for fifteen minutes. It is a credential — don't share it.

Admin passkey

The operator's own way in, and the only one that reaches every server. Rate-limited, compared in constant time, and never read from a query string.

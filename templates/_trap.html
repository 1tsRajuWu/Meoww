{# ========================================================================== _trap.html — the two paths no person is ever sent to. `utils/ai_guard` publishes them in `robots.txt` and `ai.txt`, and the guard answers a declared crawler with a decoy plus a row in `net_guard_events`. They appear here for exactly one reason: a directive that lists a path which is linked from nowhere is a directive a crawler can ignore as a mistake, and one that is *linked* — off-screen, out of the tab order, `nofollow` — is the shape a real site's link graph has. Every attribute here is load-bearing: * `tabindex="-1"` and `aria-hidden` so a keyboard user never lands on one; * `nofollow` so a legitimate crawler that follows links is not punished for a path this project listed on purpose; * `class="trap"` so the sheet keeps them off the page without `display: none`, which some collectors treat as "do not follow" and skip. ========================================================================== #}

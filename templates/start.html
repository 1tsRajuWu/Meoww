Get started

Add it once. Then switch off what you do not want.

Three steps from here to a server that does what you told it to. No account of ours sits in the middle of them: the bot holds only what Discord gives it, and the dashboard runs on this deployment, not on somebody else's service.

  1. 01

    Put it in the server

    {% if invite_url %} The full invite asks for Administrator, which is one permission bit and the reason no feature ever answers “Missing Permissions”. {% if invite_limited_url %} The least-privilege invite is the other half: only the permissions a command is known to need. {% endif %} {% else %} This deployment has no invite link configured yet — set a Discord client id and restart it. {% endif %}

  2. 02

    Open the dashboard

    Run /help in your server and press the dashboard button. That mints a one-time link for the server you ran it in — it works once, expires quickly, and reaches no other server.

  3. 03

    Decide what runs

    {{ system_count }} systems, {{ entry_count }} commands. Each system has one switch per server, and the switch decides what that server's members can type.

Three doors, and what each one reaches

A page must not offer a method this deployment does not have, so this list is read from the environment.

    {% if oauth_enabled %}
  • Discord sign-in Asks for your name and your server list, keeps only the servers where you are the owner or an Administrator and the bot is present, and re-checks that list on every request. Sign in.
    • {% endif %}
  • One-time link The ⚡ Open Dashboard button on /help. Scoped to the server it was minted in, usable once, and never a lasting credential.
  • Operator passkey The deployment owner's own door, and the only one that reaches every server at once. Off unless the host sets it.

{{ mark(sections, 'holds') }}

Where the data lives

  • One SQLite file On this deployment's own host. Settings, levels, the economy ledger, tickets, warnings and the schedule queue — no third-party database.
  • Message content Not stored. The moderation log records the action, the member, the channel and the moment; it does not keep a second copy of what somebody typed.
  • Retention {% if retention_days %}Readings older than {{ retention_days }} days are dropped by the tracker's own windows.{% else %}Nothing is kept longer than the feature that needs it.{% endif %} The privacy policy is the same file the /privacy card reads.

Thirty seconds from now

  1. Then

    The bot answers /help

    A card with this server's own systems on it, and one button that opens the dashboard for it.

  2. Then

    You see the grid

    {{ system_count }} rows, each with the switch it really has. Nothing is off by default except the systems that arrive off.

  3. Then

    Off means gone from the picker

    Not hidden, not disabled — the command leaves that server's picker, and turning the switch back on brings it back.

The dashboard is the answer to “what is it doing right now”.

Get started

Add it in three steps

There is no account to create, no card and no configuration file. Two of the three steps are pressing a button.

Invite it to your server

A server owner or an Administrator presses the button. The invite asks for Administrator — one bit, and the reason no feature ever answers “Missing Permissions”.

{% if invite_url %} Add {{ bot_name }} {% endif %} {% if invite_limited_url %} With fewer permissions {% endif %}

The smaller grant is there if you would rather hand over less — every system that needs more will say which permission it is missing rather than failing silently.

Nothing to configure

It answers the moment it joins. The systems a server has never touched arrive with sensible defaults{% if ships_off %}, and {{ ships_off | join(", ") }} arrive switched off until somebody asks for {% if ships_off | length == 1 %}it{% else %}them{% endif %}{% endif %}.

Every switch is per server and reversible: turning a system off takes its commands out of this server's picker, and turning it back on puts them back.

Open the dashboard

In Discord, run /help and press ⚡ Open Dashboard for a one-time link scoped to that server{% if oauth_enabled %}, or sign in with Discord from the {% if invite_url %}front page{% else %}sign-in page{% endif %} to see every server you administer{% endif %}.

A sign-in reaches only the servers you already run, and it is re-checked on every request — so losing the permission loses the access.

Permissions

Two invites, and what each one gives away

⚙ Administrator

The normal invite. One permission bit that includes every permission Discord has, which is why no feature ever fails with “Missing Permissions” and why a system added next month works without a second invite.

⚖ The smaller grant

Every permission the systems use — moderation, messages, level roles, voice — and nothing else. The cost is real and worth saying: a system that later needs a permission this grant does not carry will ask you for it by name.

How it works

A second bot, one click, nothing to configure

◆ Its own application

The VIP bot is a separate Discord application running the same tree. Adding it never touches the main bot — a server can run both, and `/premium status` in either reports what is active.

◷ Free in early access

While the edition is a preview it is complimentary: no purchase, no licence key, and no expiry date to watch. What it costs afterwards is a decision that will be said out loud before it happens.

✧ One command to check

/premium perks prints this same list in Discord, /premium status says what is active, and /premium invite hands back the one-click invite link.
